# مطاحن تهامة – تطبيق أندرويد

تطبيق عربي محلي لإدارة عمليات مطحنة الدقيق، مصمم للعمل دون اتصال بالإنترنت.

## الوظائف المضمنة في المشروع
- ورديات للخط الصيني والتركي، مع مالك واحد للقمح في كل وردية.
- القمح الروسي والأسترالي، بوحدة كيس 50 كجم.
- إنتاج الدقيق بأكياس 50 و25 كجم، والقشرة بأكياس 35 كجم.
- أرصدة افتتاحية مستقلة للعامري وعلان ولكل نوع وصنف.
- صرف القمح تلقائياً عند حفظ الوردية، وتحديث أرصدة المنتجات.
- تسليم الدقيق والقشرة في أي وقت مع منع الصرف فوق الرصيد.
- خزان ديزل مشترك: رصيد افتتاحي، توريدات، وصرف لكل خط ووردية.
- حساب تكلفة الديزل بمتوسط التكلفة المرجح، وحساب التكلفة لكل كيس قمح.
- سجل حركات وتدقيق لا يحذف الحركات؛ تصحيح الوردية يضيف قيوداً عكسية ويحفظ القيم السابقة.
- نسخ احتياطي يومي عبر WorkManager والاحتفاظ بآخر 30 نسخة داخل مجلد التطبيق.
- استعادة نسخة قاعدة بيانات عبر منتقي الملفات في أندرويد.

## إعدادات المشروع
- اسم التطبيق: مطاحن تهامة
- applicationId: `com.millmanager.app`
- Kotlin + Android SDK
- minSdk: 26
- targetSdk: 35
- versionName: 1.0.0

## بناء APK
1. افتح مجلد المشروع في Android Studio حديث.
2. استخدم JDK 17 أو إصداراً متوافقاً مع Android Gradle Plugin.
3. نفّذ Gradle Sync وانتظر تنزيل الاعتماديات.
4. من القائمة اختر Build ثم Build APK(s).
5. ملف APK التجريبي يظهر عادة في `app/build/outputs/apk/debug/app-debug.apk`.

## تنبيهات قبل الاستخدام الفعلي
- اختبر التطبيق على نسخة تجريبية وبأرصدة افتتاحية تجريبية أولاً.
- تصحيح وردية سبق تسليم جزء من إنتاجها يُمنع حتى لا يصبح المخزون سالباً؛ يجب مراجعة التسليمات أولاً.
- النسخ اليومية مجدولة كل 24 ساعة وقد تتأخر قليلاً حسب قيود أندرويد على مهام الخلفية. النسخ موجودة في مساحة ملفات التطبيق الخارجية، وقد تُحذف عند إزالة التطبيق؛ لذلك صدّر نسخة دورية إلى مكان آخر.
- النسخ الاحتياطي والاستعادة يحتاجان اختباراً على أجهزة فعلية قبل اعتماد التطبيق محاسبياً.
- هذا المصدر لم يُبنَ إلى APK داخل بيئة العمل الحالية لعدم توفر Android SDK وأدوات Gradle؛ لا تعتبره APK جاهزاً للتثبيت حتى تنجح عملية البناء والاختبار.
